# BUG-001: PYQ correct_answers Are AI-Inferred, Not Validated

## Summary
518/1,081 PYQs have no `correct_answer`. Claude Haiku infers answers during ingestion from
question text. Existing 563 answers are AI-inferred, not validated against official UPSC keys.

## Risk
Unreliable for a public platform. Users may learn wrong answers. Diagnostic accuracy is suspect.

## Blocker
Rahul must download official UPSC answer keys (2009–2025) from upsc.gov.in before this can be fixed.

## What's Needed
1. Download official PDFs from upsc.gov.in (Rahul action — manual)
2. Run ingestion script to map official correct_answer to existing rows
3. FEATURE-17 (PYQ Data Foundation) covers this fully

## Do NOT launch publicly until this is resolved.
